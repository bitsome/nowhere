## ⑤ 마스터 관점의 우선순위·다음 행동 추천

1. **자기 수행 수금 순환을 정리해 첫 수익을 닫는다(최우선)** — 등록 병목(Task 17·18)과 복귀 단절(Task 19·20)까지 닫혔다. 남은 단일 미해결 지점은 **자기 수행 운행의 수금/매출 반영**이다. 정책을 정해야 '수수료 매출'까지 실증이 끝난다.
2. **등록 흐름 1개로 통합(Task 18 후속)** — 라벨·필드 접기는 끝났으니, 남은 **탭 3개(붙여넣기·묶음·직접 입력)** 를 1개 흐름으로 합친다. 방금 정리한 길목이 "탭 선택"으로 다시 막히지 않게 하는 마지막 조각이다.
3. **HTTPS 고정 주소 확보(사용자 전용)** — 유입·복귀 장치(랜딩·공유 링크·위챗 파서·일괄/묶음 등록·복귀 동선)를 다 만들어 두고도 주소가 매번 바뀌어 링크가 죽는다. 도메인 + SSL 또는 Named Tunnel 확정 전까지 홍보는 실효가 없다.
4. **첫 수익 실현 1건** — `DEN-` 재고 정리 후 실제 운행 1건(모집·자기 수행·위챗 일괄 등록)을 완료→자동 정산→입금→수금 확인→수수료 매출까지 통과시킨다.
5. **복귀 동선 실동작 검증 + 계측 연결(Task 19·20 후속)** — 브라우저에서 3경로(공유 링크·딥링크·401) 복귀를 육안 확인하고, 복귀 유입을 `behavior_events`에 남겨 전환 효과를 측정 가능하게 한다.
6. **문구 해석 API 교체(LLM 키 연결)(저비용·고효과)** — Task 18이 "정확도는 다른 API로 교체 예정"이라 명시했다.
7. **미커밋 121건 커밋**(사용자 지시 후) — Task 4~20과 UI 개선분이 아직 어디에도 기록되지 않았다. 운영에서만 드러나는 결함을 네 번(500·스케줄러·데이터·OpenAI 차단) 겪은 구간이라 되돌림 지점 확보가 중요하다.
8. **운영 스모크 재실행 + 배포 절차 고정** — `smoke_endpoints.sh`·`verify_api_contract.sh`·`rehearse_*`를 배포 필수 단계로 규칙화하고, 스케줄러 동작 모니터링을 추가한다.
9. **문서 정합(Q-6)** — CHANGELOG에 Task 4~20 추가, ORDER_FLOW 수금 상태·자기 수행 경로, OPERATIONS 입금/수금 단계, TASKS `Current` 갱신. **20회차 누적 불일치.**
10. **PWA 매니페스트 카피 교정** — 앱 설치 프롬프트에 "드라이버 오더 마켓"이 그대로 노출된다. 용어 규칙 위반 → 저비용·고효과.
11. **공유 링크 정책 마감** — 토큰 만료·회수/재발급 + 유입 계측(`behavior_events`) 연결.
12. **랜딩 유입 경로 확정** — 루트(`/`) → `/welcome` 리다이렉트 vs 홍보 링크 고정 (7회차 누적).
13. **A-5 불일치 종결(20회차)** — `:show-match-reasons` 한 줄 추가 vs IMPROVEMENT_PLAN L162 문서 정정.
14. **다음 블록 확정** — 수익 축 확장(플랜 등급·PG 자동 수금·등록 흐름 통합·문구 해석 API) vs 품질 블록(Q-3 CI·Q-5) (사용자 지시 대기).
