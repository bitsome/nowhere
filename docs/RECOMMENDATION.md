# 운행 추천 알고리즘

홈 '강력추천'·'추천일정'에 노출되는 운행 추천의 기준을 정의한다.
구현: `app/Services/Order/OrderListService::recommendations()`

## 0. 서비스 지역 (서울 / 인천 / 경기만)

현재 서비스는 **서울, 인천, 경기도 지역의 운행만 취급**한다.

- 추천 대상(왕복 노선·매칭 설정·운행 이력)은 **시작지와 도착지 모두 서비스 지역 안**인 운행만 포함한다.
- 서비스 지역 밖 시·도(부산, 대구, 광주, 대전, 울산, 세종, 강원, 충청, 전라, 경상, 제주)가 명시된 운행은 추천에서 제외한다.
- 시·도명이 없는 상세 지명(판교, 잠실, 여의도 등)은 서울/경기 지역으로 간주한다.
- **공항 구분**
  - 인천공항: `T1`, `T2`
  - 김포공항: `국내선`, `국제선`
  - 같은 공항의 터미널·선은 서로 연결된다. (예: `김포공항 국내선` ↔ `김포공항 국제선`, `인천공항 T1` ↔ `T2`)

## 1. 핵심 패턴 — 샌딩(Send) ↔ 랜딩(Landing) 시간대

운행은 **샌딩(승객 실어 나르기) → 랜딩(내려주기)** 를 반복하는 흐름이다.
가장 기본이 되는 추천 알고리즘은 이 두 구간 사이의 시간 간격으로 정의한다.

| 구간 | 간격 기준 | 범위 |
|---|---|---|
| **샌딩 → 랜딩** | 샌딩 시작 시각 기준 | **30분 ~ 2시간** 사이 |
| **랜딩 → 샌딩** | 랜딩(하차) 시각 기준 | 낮(09~17시) **2시간 ~ 3시간**, 그 외(새벽·저녁·밤·야밤) **1시간 ~ 2시간** |

> **랜딩 운행의 service_time은 '항공기 도착 시각'이다.**
> 승객이 입국심사·짐찾기로 나오는 데 **30분 ~ 2시간(평균 1시간)**이 걸리므로,
> 연결 창 계산에서는 이 대기를 먼저 더한 뒤 운행 소요시간을 가산한다.
> (실하차 = 항공기 도착 + 랜딩 대기 + 운행 소요)
> - 설정: `config/recommendation.php`의 `landing_wait_minutes` (env `LANDING_WAIT_MINUTES`, 기본 **60분**)
> - 타이트하게 잡으려면 `LANDING_WAIT_MINUTES=30`처럼 줄인다.
> - 예) 랜딩 01:30(항공기 도착) → 승객 퇴장 02:30(대기 1시간) → 하차 03:30(운행 1시간) → 다음 샌딩은 하차 후 간격 창

> **2~3시간의 구성**: 구간 이동시간 + 여유 1시간을 포함한 값이다.
> - 서울 내 구→구 이동: 약 30분(비혼잡) ~ 60분(출퇴근 겹침)
>   - 출퇴근: 평일 07:30~09:30, 16:30~19:30 / 주말 16:30~19:30 (주말 아침은 안 막힘)
> - 같은 공항 터미널 간 이동: 약 15분 (인천공항 T1↔T2)
> - 타이트한 기준: 낮이 아닌 새벽·저녁·밤·야밤에는 이동이 빨라 **1~2시간**으로 잡는다.

### 예시 (매칭 설정 시간대 기준)

```
06:00 샌딩 ──(1시간)──▶ 07:00 랜딩
                         │
                    (2~3시간 대기)
                         │
                         ▼
         09:00~10:00 샌딩 ──(1~2시간)──▶ 11:00 랜딩
```

- 샌딩 06:00 → 랜딩 07:00  (샌딩→랜딩 1시간, 30분~2시간 범위 내)
- 랜딩 07:00 → 다음 샌딩 09:00~10:00  (랜딩→샌딩 2~3시간 범위 내)
- 다음 샌딩 09:00~10:00 → 랜딩 11:00  (샌딩→랜딩 1~2시간, 범위 내)

즉, 추천 대상 운행은 **내 이전 운행(랜딩) 후 간격 창 안에 시작되는 샌딩** 또는
**샌딩 후 30분~3시간 내에 도착하는 랜딩** 구조를 이어붙일 수 있는 운행을 우선한다.

## 1-1. 지역 연속성 규칙

연속 운행은 **하차지와 다음 출발지가 연결**되어야 한다. 연결 수준에 따라 추천 등급이 나뉜다.

- **일반 추천(같은 시/도)** — 같은 시/도(서울/인천/경기) 안이면 연결된다. 구 단위가 달라도 추천된다.
  - 예) 하차 `서울 중구` → 다음 출발 `서울 강남구` (일반 추천)
  - 예) 하차 `인천 송도` → 다음 출발 `인천 부평` (일반 추천)
  - 예) 하차 `서울 마포구` → 출발 `부산 해운대구` (매칭 안 됨)
- **강력추천(같은 구·같은 공항 터미널)** — 하차지와 출발지가 **같은 구/상세 구역**이거나 **같은 공항 터미널**이면 강력추천으로 우선 노출한다.
  - 예) 하차 `서울 마포구` → 출발 `서울 마포구` (강력추천)
  - 예) 하차 `인천공항 T1` → 출발 `인천공항 T1` (강력추천)
  - 예) 하차 `김포공항 국내선` → 출발 `김포공항 국내선` (강력추천)
  - 예) 하차 `인천공항 T2` → 출발 `인천공항 T1` (같은 공항이지만 터미널이 다름 → 일반 추천)

### 연속 체인 예시

```
서울 잠실 ──샌딩──▶ 인천공항 T2   (오늘 22:00)
인천공항 T1 ──랜딩──▶ 서울 중구    (내일 01:00, 야간 → 다음 출발 02:00~03:00 창)
서울 강남구 ──샌딩──▶ 인천공항 T1  (출발 서울 → 연결)
인천공항 T2 ──샌딩──▶ 서울 강남   (출발 인천 → 연결, 공운행 없이 이어짐)
```

- **연결 운행은 양방향 연속 체인**으로 추천한다. 연결1을 탄 뒤 차량이 도착하는 하차지(예: 인천공항)에서 시작하는 **연결2**까지 함께 추천한다.
- **출발지 = 차량 위치**: 추천 운행의 출발지는 반드시 직전 운행의 하차지(차량이 있는 곳)와 연결되어야 한다. 공운행이 생기지 않도록 방향이 자연스럽게 번갈아 가며 이어진다.

## 2. 추천 우선순위

- 홈은 **강력추천 / 추천일정** 두 영역으로 나뉜다.
  - **강력추천**: 연결 운행 중 **같은 구·같은 공항 터미널**(`recommend_level=strong`)만 전용 노출한다. 강력 연결 운행이 없으면 매칭 설정·이력 추천으로 대체한다.
  - **추천일정**: 그 외 추천 — 같은 시/도 연결 운행(일반)·매칭 설정·자주 다니는 노선·자주 운행한 시간을 노출한다.

1. **연결 운행(강력)** — 현재 맡은 운행(수락/운행중)의 하차지와 같은 구·같은 공항 터미널에서 시작하는 운행
2. **연결 운행(일반)** — 하차지와 같은 시/도(서울/인천/경기) 안에서 시작하는 운행
3. **매칭 설정** — 활성 매칭 설정의 지역·시간대·날짜·최소수익 조건이 일치하는 운행 (시간 중심 앞연결·뒤연결 포함)
4. **자주 다니는 노선** — 운행 이력 + 가져오기 요청 이력의 출발·하차 지역 빈도 상위 운행
5. **자주 운행한 시간** — 운행 이력에서 2회 이상 운행한 시각(시간대)의 운행

## 3. 시간 창 (오늘~내일 중심)

- 기본적으로 **지금부터 4시간 이내에 시작하는 운행**만 추천한다.
  - 예: 오늘 23:00이면 내일 03:00까지 (자정을 넘기는 4시간 창)
- **왕복 노선은 예외** — 복귀 운행 시각이 '랜딩 + 간격 창(낮 2~3시간 / 야간 1~2시간)'으로 정해지므로 지금 기준 4시간 창을 적용하지 않고, 랜딩 기준 창만 따른다. (과거 시작 운행 제외는 동일)
- **매칭 설정 조건에 맞는 운행은 4시간 창 밖이어도 추천**한다. (알람(매칭 알림)과 동일 기준)
- **과거에 이미 시작한 운행은 추천하지 않는다** (지금부터만).
- 이력 기반 추천(자주 다니는 노선·자주 운행한 시간)은 4시간 창 안 운행만 대상.

## 4. 추천 이유(recommend_reason)와 등급(recommend_level)

각 추천 운행에는 추천 근거가 표시된다.

| reason | 근거 |
|---|---|
| `연결 운행` | 맡은 일정의 하차지 → 이어지는 다음 운행 |
| `매칭 설정` | 활성 매칭 설정 조건 일치 |
| `자주 다니는 노선` | 운행/요청 이력의 자주 다니는 지역 |
| `자주 운행한 시간` | 이력에서 자주 운행한 시간대 |

연결 운행은 `recommend_level`로 등급이 나뉜다.

| level | 의미 |
|---|---|
| `strong` | 하차지와 **같은 구** 또는 **같은 공항 터미널**에서 출발 → 홈 '강력추천' |
| `normal` | 하차지와 **같은 시/도**(서울/인천/경기)에서 출발 → 홈 '추천일정' |
