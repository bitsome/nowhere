1. **라이트 모드 naive-ui primary가 브랜드 무관 초록(#18a058)으로 렌더링 (신규 발견, 검증됨)**: `utils/colors.js`의 `naiveThemeOverrides`가 `isDark ? {…} : null`로 **다크만** 오버라이드하고 라이트는 naive 기본 팔레트를 그대로 쓴다. naive-ui 2.44.1 `light.mjs` 기본 `primaryColor: #18a058`(초록)임을 직접 확인. 영향 범위: `type="primary"` 버튼 40여 곳(로그인/가입·검색·적용·저장·운행 등록·가져오기 요청·리뷰/완료 확인 등)과 naive 다이얼로그 `positiveText`(승인/거절/수락), OrderDetailView 상태 `n-tag` 등이 **라이트에서 초록 계열 naive 기본색**으로 보임 — 라이트 브랜드 파랑(#36adff)과 전면 불일치. naive-ui primary 버튼 글자는 흰색 고정이라 primaryColor만 바꾸면 밝은 파랑 위 저대비가 남아 `Button.textColorPrimary` 등 글자색 오버라이드 병행이 필요 — 전 화면에 걸친 시각 변화로 **대형 후보**.
