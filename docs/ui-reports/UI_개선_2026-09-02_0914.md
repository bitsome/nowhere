## (e) 적용하지 않은 항목과 이유 (후보)
- **공용 `UiChip.vue` 배지 스펙**: 매칭 설정·알림에서 콘텐츠 칩(`<b>라벨</b>값`)으로 사용돼 전역 변경 시 여러 화면 동시 변화. 다음 회차에 variant별 재검토 후 적용.
- **base.css hover/badge 하드코딩 색 전체 토큰화**: COLORS.md 규칙상 `colors.js`와 동시 수정 필요하고 값이 2곳(L201 vs L470)에서 갈리는 등 검증 범위 큼.
- **상태 탭 칩 블록 중복(MyMarket/RideHistory) → base.css 승격**: 구조 리팩터(큼).
- **카드 그림자·radius 통일(`--shadow-sm` 등 토큰)**: 다수 파일 교차 변경(중간).
- **OrderCard 남은 시간 "3시간 미만=틸" → 레드 교체**: 긴급도 의미 개선이지만 색상 체계 설계 판단 필요.
- **HomeView 연결고리 "일괄요청" 버튼 위치 이동(정보→이유→행동)**: 템플릿 구조 변경(큼).
- **NotificationsView 항목별 "처리할 일에서 처리" 버튼 중복 제거**: "기능 삭제 없이 노출 축소" 정책 판단 필요.
- **ActionCenter/OrderDetail 승인·거절 버튼 크기 차등, HomeView 히어로 CTA 키우기**: 주동작 시각 강조, 터치 타깃·레이아웃 검증 필요.
- **OrderCreateView 일정/셋트 n-card 중첩 해제**: 중간 규모 구조 변경.
- **커뮤니티 카테고리 6색·EmptyState 아이콘 색·UserPage 인증 배지 3색 grayscale 통일**: 디자인 결정 사항.
- **`#07120e`(브랜드 위 어두운 텍스트) 5곳 `--on-brand` 토큰화**: colors.js 동시 수정 필요(작지만 체계 변경).
