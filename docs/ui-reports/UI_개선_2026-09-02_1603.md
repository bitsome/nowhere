## (e) 적용하지 않은 항목과 이유 (후보)
- **코드 주석 내 "드라이버"(HomeView·MoreView·OrderCard 등)**: UI·에러 메시지 노출이 아니며 직전 보고서와 동일하게 비노출 주석은 유지.
- **다크 모드 브랜드 위 흰 글자 일괄 대비**: 전역 `--on-brand` 토큰 설계 필요(직전 보고서 후보 유지).
- **ChatList 타입 칩 의미-색상 불일치·라이트 대비**: 타입별 시맨틱 색 체계 설계 판단 필요(직전 보고서 후보 유지).
- **EmptyState 아이콘 5색·커뮤니티 카테고리 6색 grayscale 통일**: 디자인 결정 사항.
- **OrderCard 긴급도 색(3시간 미만 틸) 개선**: 색상 체계 설계 판단 필요.
- **배지 스펙 잔여 검토(AdminView·DashboardView·MarketView의 11px/600-700 요소)**: 대부분 eyebrow·라벨·숫자 강조로 배지(1px 6px/10px/400) 대상 아님을 확인 — 클릭형 칩(6px 12px 등)은 배지 스펙과 별개 UI 요소라 유지.
