## 목적

## 문서 설명
- `PROJECT.md`: 프로젝트 소개와 현재 상태
- `RULES.md`: 개발 및 AI 작업 규칙
- `ROADMAP.md`: 개발 단계와 우선순위 로드맵
- `TASKS.md`: 현재 진행/예정 작업
- `DATABASE.md`: DB 구조와 설계 메모
- `API.md`: API 정책과 명세 초안
- `UI.md`: 화면 구조와 UI/UX 규칙
- `COLORS.md`: 색상 토큰 체계와 팔레트
- `DASHBOARD.md`: 대시보드 허브와 기능 테스트 모듈 분리 규칙
- `DISPATCH.md`: 배차 알고리즘 설계 문서
- `GIT.md`: 브랜치, 커밋, PR 규칙
- `DEPLOY.md`: 배포 절차와 체크리스트
- `SECURITY.md`: 인증, 검증, 운영 보안 규칙
- `TEST.md`: 테스트 전략과 실행 규칙
- `CHANGELOG.md`: 변경 이력

## 운영 원칙
- 기능 변경 시 관련 문서를 함께 갱신한다.
- 설계가 바뀌면 `CHANGELOG.md`에도 남긴다.
