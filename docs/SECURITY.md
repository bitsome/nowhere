# SECURITY

## 기본 원칙
- 민감한 값은 코드에 하드코딩하지 않는다.
- 모든 비밀번호는 해시 처리된 값만 저장한다.
- 인증과 권한 검사는 서버 기준으로 처리한다.

## 인증
- 세션 기반 인증을 기본으로 사용한다.
- 로그인 성공 시 세션을 재생성한다.
- 로그아웃 시 세션 무효화 및 CSRF 토큰 재생성을 수행한다.

## 입력 검증
- 모든 폼 입력은 `FormRequest` 또는 검증 로직으로 검증한다.
- 신뢰할 수 없는 입력은 그대로 DB 또는 뷰에 사용하지 않는다.
- 검색, 정렬, 필터 조건은 허용 목록 기반으로 제한한다.

## CSRF / XSS
- 웹 폼에는 반드시 CSRF 보호를 적용한다.
- Blade 이스케이프 출력(`{{ }}`)을 기본으로 사용한다.
- HTML 출력이 필요한 경우만 제한적으로 raw 출력을 사용한다.

## 접근 제어
- 인증이 필요한 화면과 API는 `auth` 미들웨어를 적용한다.
- 관리자 기능은 별도 권한 정책 또는 게이트를 적용한다.
- 리소스 단위 권한 검사를 누락하지 않는다.

## 운영 보안
- `.env`는 저장소에 커밋하지 않는다.
- 프로덕션에서는 디버그 모드를 비활성화한다.
- 로그에 비밀번호, 토큰, 개인정보를 남기지 않는다.
